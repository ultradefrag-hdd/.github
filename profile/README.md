# UltraDefrag - Look at a Hard Disk You Own

UltraDefrag shows how files sit on a volume you select and can move them so a spinning disk reads more sequentially. The first screen is the map. The defrag is the write.

---

## Product Snapshot

Pick the drive by its letter and size, not by the order in a list. Analyze and read the picture. If the disk is an SSD, do not start a full defragment because a forum said every disk needs one. Trim and ordinary use are a different topic. This tool's moving of files is for a hard disk you have identified.

Exclude folders you do not need to touch. A boot-time pass is optional and only after you have analyzed the right disk in Windows and you can afford a restart. Stop if you selected the wrong letter. Closing the window should stop a pass that has not finished. Do not format anything from this screen.

## Live Production

Use it when a data hard disk you own has become slow to open large files you stored there, and you have already checked that the disk is healthy enough to read. Copy anything you cannot replace to another disk first if the volume has been unreliable. A defrag is not a repair for a dying drive.

Run analyze, look, and quit if you are not sure. A successful pass does not delete your files. It also does not back them up. Keep the spare copy you already trust.

---

## Analyze, Then Decide

The colored map is information. It is not an order. If the drive is the system disk and Windows is using it, a long pass can make the PC feel stuck. Do that only when you meant to, with time to let it finish or to stop it. Do not schedule a pass on a disk you plug in for other people.

---

## Setup Path

Prerequisites: A hard disk you own, identified by size and letter. A spare of important files if the disk has been unreliable.

1. Install UltraDefrag and select the letter you verified.
2. Run analyze only.
3. Stop if the disk might be an SSD or the wrong drive.
4. Start a defrag only on the data hard disk you meant.
5. Let it finish or stop it. Do not format the volume.

## Who Benefits

UltraDefrag fits a data hard disk you can name, after an analyze. It does not fit an SSD you are unsure about, a drive that is not yours, or a hope that moving files will recover a failing disk.

---

## Fixes

The wrong letter is highlighted: stop and unplug extra disks. The PC is very slow: you started a pass on the system disk. Stop it if the tool allows, and do not start another. The disk was unhealthy: restore from the spare. Defrag is not the repair.
